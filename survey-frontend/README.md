# Survey Frontend

Фронтенд-приложение для сервиса опросов и голосований, построенное на React с TypeScript.

## Описание

Это клиентская часть Survey API, которая предоставляет пользовательский интерфейс для:
- Создания и управления опросами
- Прохождения опросов
- Просмотра аналитики и результатов
- Управления пользователями

## Технологический стек

- **React 19** - UI библиотека
- **TypeScript** - Типизация
- **React Router** - Маршрутизация
- **Axios** - HTTP клиент
- **Tailwind CSS** - Стили
- **Headless UI** - Компоненты интерфейса

## Установка и запуск

### Предварительные требования

- Node.js (версии 16 или выше)
- npm или yarn
- Запущенный Survey API backend (по умолчанию на http://localhost:8000)

### Шаги по установке

1. Клонируйте репозиторий:
```bash
git clone <repository-url>
cd survey-frontend
```

2. Установите зависимости:
```bash
npm install
```

3. Настройте переменные окружения:
```bash
# Создайте файл .env в корне проекта
REACT_APP_API_URL=http://localhost:8000/api
```

4. Запустите приложение в режиме разработки:
```bash
npm start
```

Приложение будет доступно по адресу [http://localhost:3000](http://localhost:3000)

## Доступные скрипты

### `npm start`
Запускает приложение в режиме разработки. Откройте [http://localhost:3000](http://localhost:3000) для просмотра в браузере.

### `npm run build`
Собирает приложение для продакшена в папку `build`.

### `npm test`
Запускает тесты в интерактивном режиме.

## Функциональность

### Аутентификация
- Регистрация новых пользователей
- Вход в систему
- Управление сессией

### Управление опросами
- Создание новых опросов
- Добавление вопросов разных типов:
  - Одиночный выбор
  - Множественный выбор
  - Текстовый ответ
- Редактирование опросов (в статусе черновика)
- Публикация и закрытие опросов

### Прохождение опросов
- Удобный интерфейс для ответов
- Валидация ответов
- Защита от повторного прохождения

### Аналитика
- Просмотр статистики ответов
- Графическое представление результатов
- Экспорт результатов в JSON

## Интеграция с API

Фронтенд интегрирован с Survey API по следующим эндпоинтам:

- **Аутентификация**: `/api/login`, `/api/register`, `/api/user`
- **Опросы**: `/api/surveys`, `/api/surveys/{id}`
- **Вопросы**: `/api/surveys/{id}/questions`, `/api/questions/{id}`
- **Ответы**: `/api/surveys/{id}/responses`, `/api/surveys/{id}/results`
