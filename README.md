# Survey API

## Описание

API-сервис для создания, управления и анализа опросов и голосований. Поддерживает ролевую модель с авторами и респондентами, разные типы вопросов, жизненный цикл опросов и базовую аналитику. Разработан на Laravel с Eloquent ORM и MySQL.

## Ролевая модель

### Роли пользователей

**Author (Автор)**
- Может создавать, редактировать и управлять опросами
- Может публиковать и закрывать опросы
- Не может проходить опросы

**Respondent (Респондент)**
- Может проходить опубликованные опросы
- Не может создавать или управлять опросами

### Регистрация с ролями

При регистрации можно указать роль:
```json
{
  "name": "John Doe",
  "email": "john@example.com",
  "password": "password",
  "password_confirmation": "password",
  "role": "author" // или "respondent"
}
```

Если роль не указана, по умолчанию присваивается `respondent`.

## Эндпоинты

Эндпоинты спроектированы как RESTful, с использованием префикса /api для ясности. Аутентификация требуется для всех, кроме публичных (например, прохождения опросов). Методы и описания:

### Пользователи и Аутентификация

- **POST /api/register** — Регистрация пользователя (тело: name, email, password). Возвращает токен.
- **POST /api/login** — Авторизация (тело: email, password). Возвращает токен.
- **GET /api/user** — Получение профиля текущего пользователя (аутентифицировано).

### Управление Опросами (только для авторов)

- **POST /api/surveys** — Создание опроса (тело: title, description). Статус: draft. Только для авторов.
- **GET /api/surveys** — Список опросов текущего автора с пагинацией, фильтрацией и сортировкой. Только для авторов.

#### Параметры запроса для GET /api/surveys:

**Пагинация:**
- `page` (integer) - Номер страницы (по умолчанию: 1, минимум: 1)
- `per_page` (integer) - Элементов на странице (по умолчанию: 10, минимум: 1, максимум: 100)

**Фильтрация:**
- `filter` (string) - Тип фильтра:
  - `my` - Все опросы пользователя (по умолчанию)
  - `published` - Только опубликованные опросы
  - `completed` - Только закрытые опросы

**Сортировка:**
- `sort_by` (string) - Поле сортировки:
  - `created_at` - По дате создания (по умолчанию)
  - `updated_at` - По дате обновления
  - `responses_count` - По количеству ответов
- `sort_order` (string) - Направление сортировки:
  - `desc` - По убыванию (по умолчанию)
  - `asc` - По возрастанию

#### Примеры запросов:
```
GET /api/surveys
GET /api/surveys?page=2&per_page=5
GET /api/surveys?filter=published&sort_by=responses_count&sort_order=desc
GET /api/surveys?filter=completed&page=1&per_page=20
```

#### Формат ответа:
```json
{
  "success": true,
  "data": {
    "surveys": [
      {
        "id": 1,
        "title": "Опрос",
        "description": "Описание",
        "status": "published",
        "responses_count": 5,
        "questions_count": 3,
        "created_at": "2024-01-01T00:00:00.000000Z",
        "updated_at": "2024-01-01T00:00:00.000000Z"
      }
    ]
  },
  "meta": {
    "pagination": {
      "current_page": 1,
      "last_page": 3,
      "per_page": 10,
      "total": 25,
      "from": 1,
      "to": 10
    },
    "filters": {
      "filter": "my",
      "sort_by": "created_at",
      "sort_order": "desc"
    }
  }
}
```
- **GET /api/surveys/{id}** — Получение деталей опроса (включая вопросы и варианты). Только для авторов.
- **PUT /api/surveys/{id}** — Обновление опроса (тело: title, description). Только если draft. Только для авторов.
- **POST /api/surveys/{id}/publish** — Публикация опроса. Только для авторов.
- **POST /api/surveys/{id}/close** — Закрытие опроса. Только для авторов.
- **DELETE /api/surveys/{id}** — Удаление опроса. Только для авторов.

### Управление Вопросами (только для авторов)

- **POST /api/surveys/{id}/questions** — Добавление вопроса (тело: text, type, order, required, options[] для choice). Только для авторов.
- **PUT /api/questions/{id}** — Обновление вопроса (тело: text, order, required, options[]). Только если опрос draft. Только для авторов.
- **DELETE /api/questions/{id}** — Удаление вопроса. Только если draft. Только для авторов.

### Управление Вариантами (только для авторов)

- **POST /api/questions/{id}/options** — Добавление варианта (тело: text). Только для авторов.
- **PUT /api/options/{id}** — Обновление варианта (тело: text). Только для авторов.
- **DELETE /api/options/{id}** — Удаление варианта. Только для авторов.

### Прохождение Опросов (только для респондентов)

- Удобный интерфейс для ответов
- Валидация ответов по типу вопроса
- Поддержка обязательных и необязательных вопросов (поле `required`)
- Защита от повторного прохождения
- **GET /api/surveys/{id}/form** — Получение формы опроса для прохождения (вопросы и варианты). Доступно только для респондентов и если опрос опубликован.
- **POST /api/surveys/{id}/responses** — Отправка ответов (тело: answers[] с валидацией по типу). Только для респондентов и только один раз.

### Аналитика

- **GET /api/surveys/{id}/results** — Получение результатов (количество респондентов, статистика по вопросам).
- **GET /api/surveys/{id}/results/export** — Экспорт результатов в JSON.
- **GET /api/surveys/{id}/text-answers/{questionId}** — Получение текстовых ответов на вопрос с пагинацией.

Все эндпоинты возвращают JSON с HTTP-статусами (200 OK, 201 Created, 400 Bad Request и т.д.). Валидация и ошибки обрабатываются в контроллерах.

## Правила перехода состояний опросов

### Статусы опроса

- **draft** - Черновик, можно редактировать структуру
- **published** - Опубликован, можно проходить, нельзя редактировать структуру
- **closed** - Закрыт, нельзя проходить и редактировать

### Допустимые переходы

1. **draft → published**
   - Условие: опрос имеет хотя бы один вопрос
   - Результат: опрос доступен для прохождения
   - Запрет: редактирование структуры вопросов и вариантов

2. **published → closed**
   - Условие: опрос опубликован
   - Результат: новые ответы не принимаются
   - Запрет: прохождение опроса

3. **closed** (финальный статус)
   - Обратные переходы запрещены

### Ограничения по статусам

| Действие | draft | published | closed |
|-|-|-|-|
| Редактирование заголовка/описания | ✅ | ❌ | ❌ |
| Добавление вопросов | ✅ | ❌ | ❌ |
| Редактирование вопросов | ✅ | ❌ | ❌ |
| Удаление вопросов | ✅ | ❌ | ❌ |
| Добавление вариантов | ✅ | ❌ | ❌ |
| Прохождение опроса | ❌ | ✅ | ❌ |
| Просмотр результатов | ❌ | ✅ | ✅ |

## Дополнительные ограничения доступа

### Защита на уровне контроллеров

Помимо middleware-проверок ролей, все контроллеры реализуют дополнительную защиту:

- **Двойная проверка ролей**: Middleware + валидация в контроллерах
- **Владение ресурсами**: Авторы могут управлять только своими опросами и просматривать только их результаты
- **Контекстные ограничения**: Респонденты могут проходить только опубликованные опросы
- **Защита от дублирования**: Запрет на повторное прохождение опроса одним респондентом

### Правила доступа к аналитике

- **Только авторы**: Просмотр, экспорт и анализ результатов доступен только авторам опросов
- **Только свои опросы**: Авторы могут просматривать результаты только опросов, которые они создали
- **Пагинация текстовых ответов**: Для текстовых вопросов реализована постраничная загрузка с поиском

## 📚 API Документация

Полная документация API доступна в файле `/docs/api-documentation.yaml` в формате OpenAPI 3.0.

### Основные эндпоинты

#### Аутентификация
- `POST /api/register` - Регистрация пользователя
- `POST /api/login` - Вход в систему
- `GET /api/user` - Профиль пользователя

#### Управление опросами (авторы)
- `GET /api/surveys` - Список опросов с пагинацией и фильтрацией
- `POST /api/surveys` - Создание опроса
- `GET /api/surveys/{id}` - Детали опроса
- `PUT /api/surveys/{id}` - Обновление опроса
- `POST /api/surveys/{id}/publish` - Публикация опроса
- `POST /api/surveys/{id}/close` - Закрытие опроса
- `DELETE /api/surveys/{id}` - Удаление опроса

#### Прохождение опросов (респонденты)
- `GET /api/surveys/{id}/form` - Получение формы для прохождения
- `POST /api/surveys/{id}/responses` - Отправка ответов

#### Аналитика (авторы)
- `GET /api/surveys/{id}/results` - Результаты опроса
- `GET /api/surveys/{id}/results/export` - Экспорт в JSON

### Пример запроса

```bash
# Регистрация автора
curl -X POST http://localhost:8000/api/register \
  -H "Content-Type: application/json" \
  -d '{
    "name": "John Doe",
    "email": "john@example.com",
    "password": "password123",
    "role": "author"
  }'

# Создание опроса
curl -X POST http://localhost:8000/api/surveys \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_JWT_TOKEN" \
  -d '{
    "title": "Опрос о качестве услуг",
    "description": "Пожалуйста, оцените качество наших услуг"
  }'
```
